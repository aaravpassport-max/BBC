# F&O Lab — Decision Matrix

Situation → Decision, expanded from the 11-row example in the original request to real coverage across trade types and failure scenarios. Rows are marked **[LIVE]** where the current code genuinely implements this behavior (verified in the Phase 1 audit or by direct inspection while writing this document), **[PARTIAL]** where some but not all of the behavior exists, and **[GAP]** where no code implements it yet — this matrix is meant to be checked against, not aspirational prose, so the status column is load-bearing.
