Google Maps Scraper — Windows Desktop Application
Version 1.0.0

QUICK START
1. Run GoogleMapsScraper-Setup.exe (or extract GoogleMapsScraper-Portable.zip)
2. Double-click "Google Maps Scraper"
3. Enter what you are looking for and a location
4. Click START SEARCH
5. Export CSV or Excel from the results screen

REQUIREMENTS
- Windows 10/11 64-bit
- Internet connection for searches
- No Docker, Python, Node.js, or Chrome required

USER DATA
Stored in: %LOCALAPPDATA%\GoogleMapsScraper\
