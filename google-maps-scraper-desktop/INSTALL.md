# Install Google Maps Scraper (Windows)

## Option A — Installer (recommended)

1. Download **`GoogleMapsScraper-Setup.exe`** from the GitHub release / Actions artifact.
2. Double-click the installer.
3. Accept defaults (installs under `C:\Program Files\Google Maps Scraper\`).
4. Open **Google Maps Scraper** from the Desktop or Start Menu.

## Option B — Portable

1. Download **`GoogleMapsScraper-Portable.zip`**.
2. Extract to any folder (e.g. `Desktop\GoogleMapsScraper`).
3. Double-click **`Google Maps Scraper.exe`**.

## What you do NOT need

Docker, Python, Node.js, npm, Git, PowerShell scripts, or Chrome.

## First run

The app shows “Preparing the built-in search engine…” while it starts. This is normal.

## Your data

Saved under: `%LOCALAPPDATA%\GoogleMapsScraper\`
